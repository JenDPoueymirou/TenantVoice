# Development Guidelines

## Core Rules

### 1. DO NOT REMOVE ANYTHING WITHOUT EXPLICIT APPROVAL
- **IMPORTANT**: Never remove any features, code, UI elements, or functionality without explicit approval
- Always ask for permission before removing or replacing anything in the codebase
- When proposing changes, clearly identify if anything would be removed
- Wait for explicit confirmation before implementing changes that remove existing code or features

### 2. Application Focus
- This platform is specifically for tracking issues with Goldmont properties
- Focus on the specific issues and categories already defined
- Test with the address: 1273 Pacific St, Brooklyn, NY 11216

### 3. Data Visualization
- Include visual representations of collected data (charts, graphs)
- Enable exporting of graphs, statistics, and comments

### 4. Development Process
- Take "baby steps" during development
- Explain changes clearly before making them
- Get explicit approval before making ANY changes to the codebase
